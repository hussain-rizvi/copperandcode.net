Cryptocurrency hardware wallet

A secure hardware wallet integrating multiple top cryptocurrencies, with address generation, key derivation, and transaction signing written in C straight from the protocol white papers — hardened against tampering and encrypted end-to-end to its desktop companion app.

Because private keys never leave the device, every line of the signing path was written and reviewed against the source protocol specs rather than a third-party library, with the desktop companion app treated as untrusted until a signature came back verified.
